매출전표 자동화

통합매출장 업로드 → 결제수단·품목별 자동 집계

📆 선수수익/선급비용

통합매출장 기준으로 매출기준일을 정하고, 해당 기간에 발생한 품목을 선택하면 가상계좌·카드 매출/수수료(+과세분)가 자동 계산됩니다.

🗓 년도

업로드 시점에 선택된 년도가 그 파일의 모든 데이터에 표시(tag)되고, 조회 화면들은 지금 선택된 년도 데이터만 보여줍니다. 승인일자(거래일자) 기준 년도입니다.

📦 일괄 업로드

여러 파일을 한 번에 올리면 파일명으로 자동 분류합니다. 파일명 규칙: 통합매출장_학원/퀀텀1/퀀텀2, 카드매출장_학원/퀀텀1/퀀텀2, 마감내역_가상계좌/신용카드
여러 파일을 클릭 또는 드래그해서 한 번에 올려주세요

통합매출장 업로드

사업장별 xlsx 업로드 · 같은 날짜 재업로드 시 변경분만 확인창 표시

카드매출장 업로드

승인번호별 카드사(카드매입사) 매칭용 · 카드 외상매출 표에 반영됩니다

마감내역 업로드

사업장 구분 없이 1개씩 업로드하면 사이트명으로 자동 분류됩니다 · 카드매출장은 위에서 올린 파일을 그대로 사용합니다

📥 카드수수료 및 입금일 확인 업로드

시트(수강료/퀀텀1/퀀텀2)별 날짜+승인번호를 카드매출장과 매칭해서, 매칭된 건의 카드사명(N열) 기준으로 수수료율을 다시 계산하고 건별 입금일자도 반영합니다. 먼저 매출전표 탭에서 카드매출장이 업로드돼 있어야 매칭됩니다.
카드수수료 및 입금일 확인 파일을 클릭 또는 드래그해서 올려주세요

💳 카드사별 수수료율 설정 (VAN)

사업장별로 따로 관리되고, 퀀텀1·퀀텀2는 값이 없으면 학원 수수료율을 기본으로 사용합니다.
